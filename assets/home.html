SENTRA

Sentinel-2 Elastic-Net Temporal Reconstruction Application

An web platform for intelligently reconstructing cloud-masked satellite imagery, combining Elastic Net regression with geospatial integrity.

About SENTRA

Optical satellite imagery in tropical regions, such as the Ciliwung Watershed, is frequently obstructed by persistent cloud cover, significantly hindering environmental and land cover analysis.

SENTRA addresses this challenge by employing a Sliding Window approach powered by Elastic Net Regression. The system leverages multi-temporal historical contexts and multi-spectral band data to accurately impute missing pixel values (Gap-Filling) with mathematical precision while preserving true spectral fidelity.

Core Features

01 / TRAINING

Train Model

Perform image reconstruction model training by optimizing the Elastic Net regression algorithm using historical multi-temporal spatial data.

02 / EVALUATION

Evaluate Model

Validate trained model performance, delivering comprehensive evaluation reports containing regression statistical accuracy metrics and spatial structural similarity indices.

03 / RECONSTRUCTION

Image Reconstruction

Predict and reconstruct cloud-masked imagery pixels with side-by-side visual comparisons, complete with standard geospatial format export capabilities for final outputs.
